Is the order machinery actually working?

The real test says ordering other characters' events does not help. That only means something if the model can use order when order matters. So we kept the real history windows exactly as they are and replaced the label with one that is defined by order, so the right answer is known in advance.

Can a model predict what movie characters do to each other?

A course project for COMP 790-158 (Natural Language Processing, UNC Chapel Hill) by Vinir Rai and Anand Srinivasan.

Take two characters, A and B, who are both in a scene. Using only what happened earlier in the film, does A do anything to B in this scene: ask, inform, something positive or negative, pay attention to them, or a physical act? Our main question is whether the order of what other characters did to A and B helps with that prediction.

The data

MovieGraphs: 51 films, about 7,600 clips, each annotated as a graph of who is present, who does what to whom, relationships and emotions. We turn it into 29,008 decisions, one per pair per shared scene, and drop all free text so a model cannot recognise a film.

The models

Small Transformers trained from scratch on anonymous event tokens (A, B, C1…), with no pretrained weights. Four versions see more each time: the pair's own history; + their relationship and shared scenes; + other characters' events with the order removed; + the same events in order.

The test

Train on the first 70% of every film and test on the last 30%, which is what this site shows. A difference only counts if its 95% interval over films excludes zero and every random seed agrees. We wrote the order test down before running it.

What we found

  • The pair's own history helps a lot. PR-AUC 0.39 against 0.30 for chance.
  • Their relationship and how many scenes they've shared add a small, significant amount.
  • Other characters' events barely help, and their order does not help at all, within films or across films.
  • The model can learn order when a task needs it (0.97 against 0.70). So the null result comes from the data, not a broken model. See "Is order working?".

How to read the explorer

Pick a film. Each row is a pair in a held-out scene, with the in-order model's chance that A acts on B. Click a row to see what happened, all four models' predictions and the history they saw. "Confident misses" shows where the models were most sure and wrong; "Order changed the answer" shows where ordering flipped the call.

Data: Vicol et al., MovieGraphs: Towards Understanding Human-Centric Situations from Videos, CVPR 2018. Character names, scene labels and interaction verbs come from that dataset. Predictions are precomputed, mean of 3 seeds.
